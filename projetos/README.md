# Projetos de referência

| Projeto | Para quê | Como abrir |
|---|---|---|
| `00-exercicios-gdscript` | 15 exercícios com corretor automático (109 testes, 2 níveis) | Godot → Import → `project.godot` → Cmd+B |
| `01-chuva-de-estrelas` | jogo 2D mobile completo: toque, spawner, HUD, save, juice, shader de flash | idem |
| `02-arena-3d` | 3D: CharacterBody3D, câmera seguidora, joystick virtual, moedas, shaders toon + contorno | idem |

Os projetos 01 e 02 são **gabaritos**: estude e copie ideias, mas construa sua versão em `meus-projetos/`.
Quer experimentar mudanças direto no gabarito? Faça à vontade — `git checkout projetos/` desfaz tudo.

Todos os scripts são comentados em português explicando o *porquê* de cada parte.

# Pasta `modelos/`

Coloque aqui os arquivos `.glb` exportados do Blender (trilha Blender, lição B04).
O Godot importa automaticamente quando você volta para o editor.

Arquivos `.blend` (fonte) podem ficar numa pasta `fonte-blender/` na raiz do
repositório para não poluir o projeto — ou aqui mesmo, se você quiser que o
Godot reimporte direto do `.blend` (requer configurar o caminho do Blender em
Editor > Editor Settings > FileSystem > Import > Blender).

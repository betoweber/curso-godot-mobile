# Atalhos no Mac

> No Godot, os atalhos podem ser vistos/alterados em *Editor → Editor Settings → Shortcuts*.
> No Blender, vários atalhos usam **Ctrl** mesmo no Mac (o Cmd funciona em alguns como Cmd+S, Cmd+Z).

## Godot

| Ação | Atalho |
|---|---|
| Rodar projeto | **Cmd+B** |
| Rodar cena atual | **Cmd+R** |
| Parar | **Cmd+.** |
| Salvar cena | Cmd+S |
| Nova cena | Cmd+N |
| Adicionar nó filho | Cmd+A |
| Duplicar nó | Cmd+D |
| Renomear nó | F2 (ou fn+F2) / duplo clique |
| Abrir cena rapidamente | Cmd+Shift+O |
| Mover / Girar / Escalar (viewport) | W / E / S (2D) — W / E / R (3D) |
| Focar seleção | F |
| Buscar na ajuda | Option+Espaço |
| Ir para definição / ajuda do símbolo | Cmd+clique |
| Comentar linha | Cmd+K |
| Completar código | Ctrl+Espaço |
| Buscar no arquivo / no projeto | Cmd+F / Cmd+Shift+F |
| Criar `@onready var` | arraste o nó da árvore para o script segurando Cmd |

## Blender

| Ação | Atalho |
|---|---|
| Orbitar | dois dedos no trackpad / Option+clique (com Emulate 3 Button Mouse) |
| Mover a vista | Shift + dois dedos |
| Zoom | pinça / Cmd + dois dedos |
| Vistas (com Emulate Numpad) | 1 frente, 3 lado, 7 topo, 5 orto/persp, 0 câmera |
| Menu de vistas | ` (crase) |
| Buscar comando | F3 |
| Edit/Object Mode | Tab |
| Mover / Girar / Escalar | G / R / S (+ X/Y/Z + número) |
| Adicionar | Shift+A |
| Duplicar | Shift+D |
| Apagar | X |
| Selecionar tudo / nada | A / Option+A |
| Extrude / Inset / Loop cut / Bevel | E / I / Ctrl+R / Ctrl+B |
| Selecionar loop | Option+clique |
| Aplicar transformações | Ctrl+A |
| Parent | Ctrl+P |
| Pose Mode (armadura) | Ctrl+Tab |
| Inserir keyframe | I |
| Play animação | Espaço |
| Preview de material | Z → Material Preview |
| Preferências | Cmd+, |

## Aseprite (relembrando para o fluxo de jogos)

| Ação | Atalho |
|---|---|
| Exportar sprite sheet | Cmd+E |
| Nova tag (animação) | menu Frame → Tags → New Tag |
| Exportar imagem | menu File → Export As... |
